# Líneas de cron con límites de recursos (crontab del usuario ubuntu, 18 oct 2026).
# Cada job: flock -n (un lock propio) -> timeout -> prlimit --as=1.5 GiB -> python3.
# Un lock por job: si la copia anterior sigue corriendo, la nueva sale con código 1 sin hacer nada.
# Ajustar rutas si el proyecto no vive en ~/.hermes/data/memecoins.
